# Пляжная библиотека

Игра встроена в `LocationNavigator` поверх фона библиотеки.

## Настройка

- `model/config.ts`: `GENRES`, `DIRECTIONS` — названия, иконки и описания категорий; `BOOK_TITLES` — названия книг; `ROWS` — расположение полок.
- `INSTRUCTION` в этом же файле — редактируемый текст записки библиотекаря. Записка нарисована CSS, менять PNG для правки текста не нужно.
- `assets/pages/book1.png` … `book4.png` — четыре страницы с прозрачными отверстиями; `text.png` — нижний лист. Все картинки имеют одинаковые размеры и отображаются в одном масштабе.
- `model/pageAssets.ts` связывает предметы с изображениями и запиской.

## Игра

Клик по книге берёт её, клик по месту ставит на полку. Esc отменяет взятие. Занятые места обмениваются книгами; при установке книги с пола вытесненная книга возвращается на пол. Цвет не обозначает категорию.

Названия жанров и направлений скрыты, клик по иконке открывает название и описание. Названия книг на корешках видны постоянно, независимо от правильности расстановки. Фон содержит три ряда в каждом из трёх стеллажей и пустой пол; рассыпанные книги добавляет сама игра.

При первой правильной установке каждой книги случайно выпадает одна из ещё не найденных четырёх страниц. Повторная перестановка той же книги не даёт новых попыток. Вероятность учитывает оставшиеся книги: все четыре страницы гарантированно выпадают за первые 44 открытия, независимо от количества завершённых полок. Порядок страниц случайный.

За завершение выдаются `text.png` и CSS-записка. Предметы выдаются однократно и открываются из общего инвентаря. Страницы перемещаются мышью или касанием, ↩ закрывает страницу. `text.png` всегда ниже остальных листов независимо от порядка открытия.

Сохранение `beach-library-v1`, версия схемы 2: расстановка, открытые книги, страницы и завершение. Старые сохранения сохраняют расстановку; устаревшие награды заменяются. Уже завершённая библиотека получает новый комплект при входе. Позиции открытых листов сохраняются только до перезагрузки.

Проверки: `node --test tests/beachLibrary.test.mjs`, `npm run build`.
