# Звук приложения

Все звуки создаются через `audioController`. Контроллер лениво создаёт один
`AudioContext`; каждый источник подключается через собственную громкость к общему
`GainNode`. `AudioSettings` в корне приложения восстанавливает общий уровень из
`audioSettingsStore` и разблокирует Web Audio при взаимодействии пользователя.

- Разовый эффект: `audioController.playOneShot(src, { volume: 0.45 })`.
- Замена предыдущего эффекта: добавить `key: 'dialogue'` или другой ключ.
- Музыка/плеер: `createSound(src, { volume })`, затем `play()`, `pause()`,
  `setVolume(value)`. `play(true)` начинает звук заново. При размонтировании вызвать
  `dispose()`; `element` предназначен для позиции, источника, метаданных и событий.
- Синтез: `playTone(...)`; постоянные радиопомехи: `createNoiseLoop()`.

Итоговый уровень радио:

`общая громкость × громкость радио × RADIO_MIX.station × сила сигнала`.

Для помех вместо коэффициента станции используются `RADIO_MIX.noise` и уровень
помех. У викторины собственный множитель `audioVolume`. Локальные настройки не
перезаписываются общим ползунком. Ноль общего уровня выключает все источники;
изменение уровня не перематывает и не перезапускает воспроизведение.

Не создавать `Audio`, `AudioContext` и подключения к `destination` в компонентах.
Настройка громкости сохраняется под ключом `beach-party-audio`.

Проверки: `node --test tests/audioController.test.mjs`.
