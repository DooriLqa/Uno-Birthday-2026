# Unu Birthday 2026

## Быстрый старт

### Требования

- Node.js 20.19+ или 22.12+ (рекомендуется актуальная LTS-версия)
- npm 10+ — устанавливается вместе с Node.js

Проверить установленные версии можно командами:

```bash
node --version
npm --version
```

### Установка и запуск

1. Клонируйте репозиторий и перейдите в папку проекта:

   ```bash
   git clone <URL_РЕПОЗИТОРИЯ>
   cd uno-birthday
   ```

2. Установите зависимости. Эта команда также подключит Git-хуки Husky:

   ```bash
   npm install
   ```

3. Запустите сервер разработки:

   ```bash
   npm run dev
   ```

4. Откройте адрес из вывода команды (обычно `http://localhost:5173`) в браузере.

### Проверка перед отправкой изменений

```bash
npm run format:check  # проверить форматирование
npm run lint          # проверить код
npm run build         # проверить production-сборку
```

Для автоматического форматирования используйте `npm run format`.

Проект-поздравление для Юни

## Стек

- React 19 + TypeScript + Vite
- React Router — маршруты каталога и игр
- Zustand с `persist` — прогресс сохраняется в `localStorage`
- PixiJS — игровая сцена
- Локальная UI-система в `src/shared/ui` — лёгкая и легко меняется через CSS
- ESLint, Husky и lint-staged — линт запускается для staged-файлов перед коммитом

## Команды

```bash
npm run dev
npm run lint
npm run format
npm run build
```

## Структура

Код разделён по FSD: `app`, `pages`, `widgets`, `features`, `entities`, `shared`.
Каждая мини-игра лежит в отдельной фиче внутри `src/features` и содержит собственный компонент и CSS-оформление. Каталог мини-игр находится в `src/entities/game/model/games.ts`.

Prettier запускается для всего проекта перед каждым коммитом, затем lint-staged проверяет изменённые файлы.

## Радио Бони

В каталог добавлена мини-игра `beach-radio`:

- общая валюта `🐾` хранится отдельно в Zustand и сохраняется через `persist`;
- радиоприёмник попадает в отдельный общий инвентарь после победы в квизе;
- квиз содержит пул вопросов и хранит вес каждого вопроса: `0` — не встречался, `1` — встречался и был ошибочно отвечен, `2` — был решён правильно;
- на каждом шаге случайно выбирается вопрос из пачки с минимальным весом; память квиза можно стереть через Dev Tools;
- `102.9 MHz` — единственная правильная станция, её плейлист состоит из последовательности треков;
- аудио радио живёт вне React-компонента и продолжает играть после закрытия модального окна;
- все станции воспроизводятся в фоне, а слышимость управляется через Web Audio GainNode;
- фоновые радиопомехи генерируются через Web Audio API и становятся тише возле правильной частоты.

Для реальных записей используйте папки `public/audio/radio/station-01/` ... `station-08/`.
У правильной `station-06` можно разместить 20+ файлов (`track-01.mp3`, `track-02.mp3` и т.д.),
остальным станциям нужен один `track-01.mp3`.

Частоты станций: `88.7`, `91.3`, `94.8`, `97.6`, `100.2`, `102.9`, `105.1`, `107.4 MHz`.
